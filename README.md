# XiaoxinStickyNote 便签

一款**桌面便签（桌面小纸条）**应用，基于 **Tauri 2（Rust 后端）+ Vite + TypeScript** 构建。

每条便签是一个**独立窗口**，关闭后收进**系统托盘**（不占用任务栏）；支持全局快捷键呼出、全局速记、Markdown 编辑、划词翻译、贴边自动收起（QQ 风格）等能力。数据全部保存在本地，不上传任何服务器。

## 功能特性

### 1. 多窗口便签
- 每条便签都是独立的无边框、置顶、透明背景窗口，可自由拖动、缩放。
- 关闭便签 → **仅隐藏到系统托盘**，不会真正退出；随时可重新呼出。便签仍在「打开集合」中，会列在托盘右键菜单里。
- 新建便签数量不限，各自独立保存内容与样式。

### 2. 全局快捷键（呼出 / 速记 / 翻译 / 配色）
- 一套可自定义的全局快捷键，无需聚焦便签窗口即可触发（详见[全局快捷键](#全局快捷键)）。
- **全局快捷速记**：在任何软件里选中一段文字，按下快捷键即可新建便签并**自动把选中内容填入**便签（无需手动复制粘贴）。
- **「呼出便签」与「全部关闭」可设为同一个快捷键**：此时它作为「切换」使用——有便签可见则全部隐藏，否则全部呼出。不会再出现「弹出又立刻收起」。

### 3. Markdown 编辑与预览
- 每条便签支持 **编辑 / 预览 / 左右分栏** 三种模式。
- 内置多套预览主题（默认暖色、GitHub、玫瑰枯木暗色、Solarized），并支持**上传自定义 CSS** 文件定义自己的渲染风格（样式仅作用于预览区）。

### 4. 深色 / 浅色主题
- 一键切换浅色（暖白）/ 深色，整套界面跟随 CSS 变量统一换肤。
- 快捷按钮或「设置」中均可切换，所有便签窗口实时联动。

### 5. 划词翻译
- 选中文字后，点击工具栏「翻译」即可翻译；翻译方向**按输入语种自动判断**（含中文 → 配置的外文；外文/英文 → 配置的中文）。
- 支持翻译方式：**MyMemory（免密钥，开箱即用）**、**百度翻译**、**有道翻译**（后两者需在「设置」中填入对应的 AppID / 密钥）。
- 翻译区**默认隐藏**，需要时用「翻译」按钮或快捷键呼出；翻译结果可一键复制。

### 6. 自定义标题与历史列表
- 每条便签顶部有可编辑的**标题**输入框；历史便签列表优先展示标题，无标题时展示内容摘要。
- 标题栏「历史」按钮可查看 / 切换已有便签。

### 7. 靠边自动收起（QQ 贴边风格）
- 开启后，把便签拖到屏幕边缘附近、鼠标离开时便签会**自动收起到边缘**；鼠标移回边缘附近时**平滑弹出**。
- 弹出动画带缓动（easeOut 风格），收起/弹出过程优雅，且会**完整弹出到屏幕内**（修复了以前部分内容残留屏幕外的问题）。
- 若呼出后鼠标立刻离开，便签会在完全弹出后做一次检测，鼠标不在便签内则自动收起。

### 8. 个性化外观
- **字体颜色 / 背景颜色**：每条便签可独立设置文字色与背景色（背景色仅作用于便签卡片，不影响卡片外透明区）。
- **字号**：增大 / 减小快捷键或工具栏调整。
- **置顶**：每条便签可独立切换是否总在最前。
- **全局默认背景图片**：在「设置」中可选一张图片作为所有便签的默认背景；单张便签也可单独设置自己的背景，优先于全局。背景图与透明背景的磨砂（模糊）效果统一由「毛玻璃效果」控制。

### 9. 大模型整理格式（AI 格式化）
- 工具栏在「Markdown 预览 / 拆分」旁提供两个紧凑按钮：**MD**（整理为干净的 Markdown）与**文本**（整理为干净的纯文本）。
- 点击后调用你在「设置」中配置的 **OpenAI 兼容大模型**（兼容 OpenAI、DeepSeek、通义、智谱等任意 OpenAI 格式接口），把便签内容**重新排版、去除冗余、统一格式**，但不篡改原意、不编造信息。
- 整理结果以 **git 风格的差异对比**弹出（红 `-` 删除 / 绿 `+` 新增 / 灰上下文），你可以逐行核对，点「接受」才把内容替换进便签，点「取消」则原样保留——**不会悄无声息地覆盖你的内容**。
- 需要先在「设置 → 大模型」填入 Base URL、API Key、模型名（均可留空使用默认 OpenAI 配置）。

### 10. 自动保存与本地存储
- 内容、尺寸、位置、标题、颜色、Markdown 模式、翻译开关、各项开关状态均**自动持久化**，无需手动保存。
- 全部数据保存在本地 `%APPDATA%/XiaoxinStickyNote/` 目录，离线可用、隐私可控。
- **每条便签都是独立的一个 JSON 文件**（`xiaoxin_sticky_note_<id>.json`），可在资源管理器里直接找到并用记事本打开查看（文件内是带排版的 JSON，正文以 HTML 形式存储）；在「设置 → 便签存储路径」可把存储目录改到你想要的位置，修改后原有便签会**自动迁移**到新目录。

## 窗口与操作

便签窗口由以下部分组成：

- **标题栏**：设置按钮（齿轮）、主题切换（月/日图标）、标题输入框（可编辑便签标题）、历史按钮（☰）、新建按钮（+）、置顶按钮（📌）、最大化、最小化到托盘（▽）、关闭（✕）。
- **编辑区**：直接输入文字；支持 Markdown（开启预览/分栏时渲染）。
- **工具栏**（编辑区下方）：
  - 字体颜色 / 背景颜色选择器（含「按当前颜色上色」按钮）。
  - 文字大小下拉（也可配合全局快捷键增大/减小）。
  - 翻译区开关按钮（显示/隐藏翻译区）。
  - **Markdown 预览 / 拆分**按钮（切换编辑、预览、左右分栏）。
  - **MD / 文本**按钮：调用大模型把便签内容整理为干净的 Markdown 或纯文本（见[大模型整理格式](#9-大模型整理格式ai-格式化)）。
- **翻译区**（默认隐藏，可拖动分隔条调整高度）：
  - 目标语言选择、翻译按钮、复制译文按钮。

### 关闭 vs 最小化
- **关闭（✕）**：隐藏便签到托盘（仍在打开集合，可在托盘右键重新打开）。
- **最小化到托盘（▽）**：同样隐藏到托盘。
- 真正退出：右键托盘图标 → 「退出」。

## 全局快捷键

所有快捷键均可在「设置」中**点击「录制」后按下组合键**重新绑定。默认值如下：

| 动作 | 默认快捷键 | 说明 |
| --- | --- | --- |
| 字体颜色 | `Ctrl+Shift+C` | 聚焦便签时，套用当前字体颜色 |
| 字体背景色 | `Ctrl+Shift+B` | 聚焦便签时，套用当前背景颜色 |
| 增大字号 | `Ctrl++` | 放大便签文字 |
| 减小字号 | `Ctrl+-` | 缩小便签文字 |
| 翻译 | `Ctrl+Shift+T` | 翻译当前选中/输入内容（自动呼出翻译区） |
| 呼出便签（全局） | `Ctrl+O` | 把所有打开的便签显示到前台 |
| 全部关闭（全局） | `Ctrl+Shift+X` | 把所有便签隐藏到托盘（仍在打开集合） |
| 新建便签（全局速记） | `Ctrl+Shift+N` | 新建便签；若当前有其他软件选中了文字，自动填入 |

> **提示**：把「呼出便签」和「全部关闭」设为**同一个快捷键**，即可实现「一键在全部显示 / 全部隐藏之间切换」。

## 设置说明

点击便签标题栏的「设置（齿轮）」按钮打开设置弹窗，包含：

- **快捷键**：列出上述全部动作，逐条「录制 / 确定」重新绑定；同一组合可绑定到多个动作（例如「呼出」与「全部关闭」共用）。
- **翻译**：
  - 翻译方式：MyMemory（免密钥）/ 百度翻译 / 有道翻译。
  - 百度 / 有道需分别填入 AppID+密钥 / AppKey+密钥。
- **自动语言方向**（仅在目标语言选「自动」时生效）：
  - 中文译为：默认英文（可改日/韩/法等）。
  - 英文/其他译为：默认中文。
- **外观**：
  - 主题：浅色（暖白）/ 深色。
  - 靠边收起：开启贴边自动收起 / 弹出（QQ 风格）。
  - 背景图片：选一张作为全局默认背景；可清除；支持预览。
- **大模型（整理格式）**：
  - Base URL：OpenAI 兼容接口地址，可空（默认 `https://api.openai.com/v1`）。
  - API Key：必填，留空则「MD / 文本」按钮会提示先配置。
  - 模型名：可空（默认 `gpt-4o-mini`）。兼容 DeepSeek、通义、智谱等任意 OpenAI 格式端点。
- **便签存储路径**：
  - 存储目录：每条便签的 JSON 文件所在位置，可空（默认 `%APPDATA%/XiaoxinStickyNote`）。
  - 「浏览」用系统文件夹选择器选目录；「打开文件夹」用资源管理器打开当前目录（便签是标准 JSON 文件，**可用记事本直接打开查看**）；「恢复默认」清空回默认目录。
  - 修改并保存后，原有便签会**自动迁移**到新目录，不会丢失。
- **Markdown 样式**：
  - 主题：默认（暖色）/ GitHub / 玫瑰枯木（暗色）/ Solarized / 自定义。
  - 自定义：上传自己的 CSS 文件（样式仅作用于预览区），可「编辑文件」「重新载入」实时生效。

> 设置保存后自动重新注册全局快捷键，并即时应用到所有便签窗口。

## 数据存储

所有数据保存在本地（目录可在「设置 → 便签存储路径」中自定义，以下为默认值）：

```
%APPDATA%/XiaoxinStickyNote/
├── settings.json          # 全局设置（快捷键、翻译方式/密钥、主题、背景、Markdown、大模型、存储路径等）
├── open_notes.json        # 当前「打开中」的便签 id 列表（用于呼出 / 托盘菜单）
├── md_custom.css          # 自定义 Markdown 样式文件（若使用）
└── xiaoxin_sticky_note_<id>.json  # 每条便签一个文件：内容、标题、颜色、尺寸、Markdown 模式等
```

- **每条便签都是独立的一个 JSON 文件**：在资源管理器里可直接找到并用记事本打开查看。文件内是带排版的 JSON，正文以 HTML 形式存储（例如在 `<p>` 标签里）。
- 修改「便签存储路径」后，旧文件会**自动移动到新目录**，历史不丢。
- 旧版（Python/tkinter）便签若存放于同目录、命名一致，亦兼容读取。
- 数据完全本地化，不依赖网络（翻译与「大模型整理格式」功能除外，需调用对应服务）。

## 托盘菜单

右键点击系统托盘图标，菜单结构为：

```
显示便签            ← 呼出（显示）所有打开的便签
─────────────
<便签标题或首行摘要>   ← 点击其中一项即呼出该便签（显示并展开贴边收起的便签）
<便签标题或首行摘要>
...
─────────────
退出                ← 真正退出程序
```

- 「显示便签」与「退出」行为不变；列表中的便签项会**随新建 / 关闭 / 删除实时更新**。
- 仅列出真实存在的窗口，避免残留 id 出现在菜单中。

## 开发 / 构建 / 打包

```bash
# 安装依赖
npm install

# 开发模式（带热更新）
npm run tauri dev

# 仅构建前端
npm run build

# 仅构建 Rust 后端（在 src-tauri 目录下）
cd src-tauri && cargo build --release

# 构建 + 打包为安装包 / 便携 exe，并复制到项目根目录
npm run pack
```

打包产物位置：

- 安装包：`src-tauri/target/release/bundle/nsis/XiaoxinStickyNote_1.0.0_x64-setup.exe`
- 便携版：`src-tauri/target/release/xiaoxin-sticky-note.exe`

`npm run pack` 会在打包完成后，把上述两个文件再复制一份到项目根目录（即仓库中的 `XiaoxinStickyNote_1.0.0_x64-setup.exe` 与 `xiaoxin-sticky-note.exe`），方便取用与发布。

## 常见问题

- **便签关了还在托盘？** 是的。关闭只是隐藏到托盘，可在托盘右键菜单重新打开，或按「呼出便签」快捷键全部显示。
- **翻译没反应？** 检查「设置」中是否已选择翻译方式并（对百度/有道）填入密钥；MyMemory 无需密钥。
- **全局快捷键不生效？** 确认没有与其它全局软件冲突；修改后点「保存」会自动重新注册。
- **数据在哪？** 见[数据存储](#数据存储)；如需备份，复制整个 `XiaoxinStickyNote` 文件夹即可。
- **便携版和安装版区别？** 仅分发方式不同，功能完全一致；数据目录一致。
